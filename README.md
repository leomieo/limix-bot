# Limix Bot

Ứng dụng chat chạy trên máy bạn để điều hành một đội bot AI — kèm kết nối Telegram, Zalo.
Tác giả: **Leox ৹ Limix AI**.

## Tải về (Windows)

Vào [Releases](https://github.com/leomieo/limix-bot/releases/latest) → tải `LimixBot-setup.exe` → chạy.
Bản cài chưa ký số: nếu Windows SmartScreen báo "Unknown publisher", bấm **More info → Run anyway**.

## Build

GitHub Actions → **Limix Bot Windows** → **Run workflow**. Quy trình build trên máy Windows của GitHub,
kiểm tra máy chủ đóng gói khởi động được, rồi đăng bản phát hành.

Tài liệu gốc của OpenMausBot vẫn nằm trong thư mục [docs/](docs/).
