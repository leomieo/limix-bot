# Remote access / Truy cập từ xa

## Tiếng Việt

Dùng **Kết nối điện thoại** trong menu tài khoản để tạo liên kết ghép nối. Mở liên kết trên thiết bị muốn kết nối. Máy chạy Limix Bot cần duy trì kết nối mạng và hoạt động trong suốt phiên. Xem [hướng dẫn chạy trên máy chủ riêng](TRIEN_KHAI_CLOUD_24-7.md) nếu muốn tự vận hành.

## English

Use **Connect phone** in the account menu to create a pairing link. Open the link on the device you want to connect. Keep the computer running Limix Bot online throughout the session. See the [self-hosting guide](TRIEN_KHAI_CLOUD_24-7.md) if you want to run it on your own server.
