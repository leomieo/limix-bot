# Limix Bot 0.3.54

English

The verified Leox super administrator gets Cloud access automatically, without a trial request or self-approval. The profile menu shows one Limix sign-out action.

Tiếng Việt

Tài khoản super admin Leox được xác thực sẽ có quyền dùng Cloud tự động, không cần đăng ký hay tự duyệt dùng thử. Menu tài khoản chỉ hiện một mục đăng xuất Limix.

# Limix Bot 0.3.53

English

The Leox account can open Limix Cloud administration from Cloud settings using its existing Limix sign-in. Browser sessions end when the page is closed or reloaded. Owner authorization is enforced by the server.

Tiếng Việt

Tài khoản Leox có thể mở Quản trị Limix Cloud từ cài đặt Cloud bằng phiên đăng nhập Limix hiện tại. Phiên trình duyệt kết thúc khi đóng hoặc tải lại trang. Máy chủ kiểm tra quyền quản trị.

Limix Bot 0.3.52

## Tiếng Việt

- Limix Cloud: đưa đội bot lên mây, chuyển bot sang mây, ngủ/thức, chạy 24/7 khi tắt máy (đang thử, duyệt tay).
- Tạm dừng từng bot hoặc phòng ban.
- Bot nhẹ và nhanh hơn.
- Gửi/nhận tệp nén và mọi loại tệp.
- Giao diện riêng, ảnh đại diện, nút bật/tắt từng nhóm công cụ; bot đổi cài đặt ứng dụng có thể hoàn tác.
- Hơn 50 bản sửa lỗi từ bản cập nhật nền.

## English

- Limix Cloud: move your bot team to the cloud, move bots, sleep/wake, keep running 24/7 with your computer off (beta, hand-approved).
- Pause a single bot or department.
- Lighter, faster bots.
- Send and receive archives and any file type.
- Custom themes, avatars and per-group tool switches; bot changes to app settings can be undone.
- 50+ fixes from the upstream update.
