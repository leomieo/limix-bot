# Limix administration / Quản trị Limix

## Tiếng Việt

Giao diện quản trị tập trung có các mục tài khoản, gói dịch vụ, tổ chức, giao dịch, mã ưu đãi và Limix Cloud. Chỉ người có quyền quản trị mới được truy cập. Vai trò trong danh bạ tổ chức dùng để sắp xếp tài khoản. Việc tạo mã ưu đãi hiện chưa áp dụng vào thanh toán.

## English

The administration interface covers accounts, service plans, organizations, transactions, vouchers and Limix Cloud. Access requires administrative permissions. Directory roles help organize accounts. Voucher creation is currently separate from checkout.
