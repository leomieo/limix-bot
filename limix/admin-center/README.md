# Quản trị Limix / Limix administration

[Tiếng Việt](#tiếng-việt) · [English](#english)

## Tiếng Việt

Người có quyền quản trị có thể quản lý tài khoản, tổ chức, gói dịch vụ, giao dịch, mã ưu đãi và Limix Cloud. Có thể dùng vai trò trong danh bạ để sắp xếp tài khoản. Mã ưu đãi hiện chưa dùng được khi thanh toán.

## English

Administrators can manage accounts, organizations, service plans, transactions, vouchers and Limix Cloud. Directory roles help organize accounts. Vouchers are not yet supported at checkout.
