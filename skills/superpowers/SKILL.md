Start with skills/using-superpowers/SKILL.md within this bundle. A reference to superpowers:<name> means skills/<name>/SKILL.md under the same root. Read the applicable workflow and its referenced resources before executing it. Source assets and scripts are relative to the individual workflow directory. If your environment cannot read the bundle, report which resource is unavailable.

For new behavior, clarify the design, record a plan and drive implementation with failing tests. For defects, establish the cause before changing code. Use independent review and verify the user-visible outcome before reporting completion. Route scoped assignments to existing team members when delegation is available and authorized. Otherwise follow executing-plans in the current conversation. Apply the person's project instructions, permissions and release decisions throughout. Get consent before starting the optional local visual companion and set SUPERPOWERS_DISABLE_TELEMETRY=1 when launching it.
